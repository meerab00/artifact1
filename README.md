# Algebra Studio — Abstract Algebra Artifact 1

A responsive, browser-based learning workspace for the core topics in Abstract Algebra Artifact 1.

## Live website
https://meerab00.github.io/artifact1/

## Sections
1. **Abelian Group Classification** — explore finite abelian group decompositions, including order 72.
2. **Group Builder** — construct cyclic groups and direct products; inspect elements, inverses, element orders and Cayley tables.
3. **Calculator** — standard arithmetic calculator.
4. **Permutation Lab** — cycle notation, composition, inverse, order and parity.
5. **Dihedral Group Lab** — rotations, reflections, group order and element orders.
6. **Exercises** — guided questions with answers and explanations.
7. **Notes & Formulas** — concise revision notes.
8. **Code Lab** — short algorithms behind the calculations.
9. **Real-World Applications** — clock arithmetic, symmetry and rearrangements.

## How to use
Open the live website and select a section from the navigation. Each section opens its own dashboard. The tools run in the browser; no account, database or server is required.

## Technology
- HTML5
- CSS3 (responsive layout)
- Vanilla JavaScript
- GitHub Pages

## Scope
This repository is limited to **Artifact 1** topics: finite abelian groups, group construction, permutations, dihedral groups and the associated calculator/exercises.
